# qa_python
**Юнит-тесты для приложения BooksCollector**
## Тесты для проверки метода init
1. Проверяю, что словарь books_genre является пустым.
2. Проверяю, что список favorites пустой.
3. Список genre содержит доступные жанры
4. Список genre_age_rating содержит жанры с возрастным рейтингом.
## Параметризованный тест
1. Название книги может содержать от 1 до 40 символов.
## Проверяем метод add_new_book
1. Одну и ту же книгу можно добавить один раз.
## Устанавливаем книги жанр
1. Добавляем книгу в словарь books_genre.
2. Устанавливаем книге жанр, который входит в список genre.
## Получаем жанр книги по её имени
1. Добавляем книгу в словарь books_genre.
2. Устанавливаем жанр книги, метод set_book_genre.
## Получаем список книг с определённым жанром
1. Добавляем книгу в словарь books_genre.
2. Устанавливаем жанр, метод set_book_genre.
## Получаем словарь books_genre
1. Добавляем книгу в словарь books_genre.
2. Устанавливаем жанр, метод set_book_genre.
3. Получаем словарь по значению.
## Получаем книги которые подходят детям
1. Добавляем книгу в словарь books_genre.
2. Устанавливаем жанр, метод set_book_genre.
## Добавляем книгу в Избранное
1. Добавляем книгу в словарь books_genre.
## Удаляем книгу из Избранного
1. Добавляем книги в словарь books_genre.
2. Добавляем книги  в Избранное.
## Получаем список Избранных книг
1. Добавляем книги в словарь books_genre.
2. Добавляем книги  в Избранное.
